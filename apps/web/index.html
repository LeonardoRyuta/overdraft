Why this gap exists

Aqua's design makes phantom depth possible, its immutability makes it stick, and until now nobody was computing the ratio that reveals it.

Virtual balances

Aqua is a registry, not a pool. Tokens stay in the maker's wallet; the contract stores allowance records. So $100k of real balance can quote $300k of depth across many positions. That's the feature — and the loophole.

Immutability

Aqua strategies are immutable once shipped. A misconfigured or under-backed position can't be edited — it can only be docked or left running, advertising depth it can't deliver.

Nobody computed it

Quoted depth is published; backed depth is not. The ratio between them is a position's real solvency. Aqua's eight audits cover the contracts — not whether a maker's wallet can honour what its positions advertise.

coverage = min(wallet, allowance→Aqua) / Σ committed

How it works

Four tools, run in order: measure the gap, verify it executes as quoted, ship the instruction that refuses to overquote, and serve it all over live data.

Measure coverage engine

Enumerate every active position from The Graph — one schema deployed per network — then read each maker's real backing live on-chain: min(balanceOf, allowance→Aqua) against summed virtual balances. USD priced via DefiLlama; positions whose commitment exceeds a token's total supply are flagged degenerate and excluded from the headline. Sampled top-15 positions matched on-chain rawBalances 15/15.

Verify the Honesty Probe, mainnet fork

Take a real, live wstETH/1INCH position and prove two things on a Foundry fork. First, quote equals execution to the wei when backing exists. Then, ask the quote for depth the maker can't cover — it happily returns 15,818 1INCH against a maker holding ~11,298 — and watch the swap revert at settlement.

Fix SolvencyGuard, a SwapVM instruction

A custom SwapVM instruction appended to a maker's program. Unguarded, a position quotes 90,909 WETH backed by 5 WETH — an 18,181× overcommit. With the one-byte guard appended, the same quote reverts InsufficientCoverage, naming exactly what's missing — refused at quote time, not at settlement. Backed makers are never blocked; only the overcommit is.

cd apps/mcp && npm install

# optional — use live Graph data instead of the

    • aqua_coverage_summary — network totals: quoted vs. backed, aggregate coverage, phantom, under-backed and degenerate counts.

    Architecture

    One registry, two enumeration tracks into the coverage engine — which fans out to the MCP and the leaderboard — plus a fork branch that verifies the finding and ships the fix.

    Index — Subgraph + Substreams on one schema, both Graph tracks.
    Diagnose — the engine joins quoted depth with live-read backed depth into a per-(maker, token) ratio.
    Verify — a Foundry fork probe proves quote-vs-execution divergence and phantom fills.
    Fix — SolvencyGuard makes a position refuse to quote beyond real backing.
    Serve — an MCP server, a SKILL, and this public leaderboard over the same data.
